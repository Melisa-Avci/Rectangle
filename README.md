# Rectangle Project

## Genel Bakış
Rectangle projesi, Java dilinde nesne yönelimli programlama yaklaşımıyla geliştirilmiş basit bir geometrik modeldir. Proje, dikdörtgen nesnesi üzerinden temel hesaplamaları gerçekleştirmeyi hedefler.

## Kullanılan Parametreler
- **width (genişlik)**: Dikdörtgenin yatay kenar uzunluğu.  
- **height (yükseklik)**: Dikdörtgenin dikey kenar uzunluğu.  

## Fonksiyonlar
- **getArea()**: Alan hesaplama (`width * height`).  
- **getPerimeter()**: Çevre hesaplama (`2 * (width + height)`).  

## Amaç
Bu proje ile:  
- Temel geometrik hesaplamaların nesne yönelimli yapıda modellenmesi,  
- Parametreler üzerinden farklı dikdörtgen örneklerinin oluşturulması,  
- Alan ve çevre hesaplamalarının test edilmesi amaçlanmıştır.
